# Planned Frontend Structure

The `frontend/` folder is **not created yet**. It will be generated by the official Vite React + TypeScript setup, then organised as below. Nothing here is built yet.

```text
frontend/
├── .env.example          # placeholder template (see below)
├── package.json
├── tsconfig*.json
├── vite.config.ts        # includes the Tailwind v4 Vite plugin
├── index.html
├── public/
├── src/
│   ├── main.tsx
│   ├── App.tsx
│   ├── index.css         # Tailwind v4 import + PRD theme colours
│   ├── routes/           # router setup and protected-route logic
│   ├── pages/            # the 9 approved pages (added one at a time)
│   ├── components/
│   │   ├── layout/       # header, mobile navigation, page shell
│   │   ├── ui/           # buttons, inputs, cards, loading/empty/error states
│   │   └── features/     # pieces tied to one workflow (skills, requests, reviews, AI matches)
│   ├── services/         # Supabase Auth client and calls to FastAPI (the only network code)
│   ├── context/          # signed-in user / session state
│   ├── hooks/            # reusable data hooks
│   ├── types/            # shared TypeScript types
│   └── utils/            # formatters and validators
└── tests/                # frontend tests
```

## Pages (PRD section 3)

Landing `/`, Register `/register`, Login `/login`, Dashboard `/dashboard`, My Profile `/profile`, Explore `/explore`, Member Details `/members/:id`, Requests `/requests`, AI Matches `/ai-matches`.

## Tailwind CSS v4

- Installed with the official `@tailwindcss/vite` plugin.
- Enabled with `@import "tailwindcss";` in `src/index.css`.
- No `tailwind.config.js` or `postcss.config.js` is assumed. Theme colours go in a CSS `@theme` block.
- PRD palette: navy `#142D4E`, teal `#087E8B`, off-white `#F5F8FB`, gold `#F2B45D`.

## Frontend `.env.example` template (to be created with the frontend)

Placeholders only. Vite exposes only variables prefixed with `VITE_`, so never put secrets here.

```text
VITE_SUPABASE_URL=your-supabase-project-url
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_your-key-here
VITE_API_BASE_URL=http://localhost:8000
```
